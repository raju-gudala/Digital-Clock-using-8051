# Digital Clock using 8051

A digital clock implementation built using the 8051 microcontroller.

## Overview

This project implements a real-time digital clock using the 8051 microcontroller, displaying hours, minutes, and seconds.

## Hardware

- 8051 Microcontroller (AT89C51 / equivalent)
- 16x2 LCD Display
- Supporting components (crystal oscillator, resistors, capacitors)
